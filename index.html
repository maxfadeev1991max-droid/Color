Как подключить общую базу (один раз)
  1. Один из вас заходит на jsonbin.io → «Войти через Google» (один клик, без паролей).
  2. Слева открывает страницу API Keys и копирует X-Master-Key.
  3. Вставляет этот ключ в поле «Ключ» ниже, поле «ID базы» оставляет пустым → нажимает «Подключить». Приложение создаст общее хранилище и покажет его ID.
  4. Оба значения — Ключ и ID базы — нужно передать коллеге (например, сообщением) и ввести у него в те же поля → «Подключить». После этого оба работают с одной базой.

Бесплатный аккаунт jsonbin.io даёт разовый лимит запросов (не обновляется каждый месяц) — для двух колористов его хватает надолго. Обновление не мгновенное: нажимайте «🔄 Обновить» у «Библиотеки», чтобы подтянуть свежие рецепты коллеги.

🧠 Обучение и мозг команды

Подсказки строятся по вашим же сохранённым рецептам и журналу правок на этом телефоне — чем больше рецептов накоплено (особенно с указанным именем мастера и фото Эталона), тем точнее профиль.

Приложение случайно берёт цвет одного из сохранённых Эталонов и прячет его рецепт. Задача — подобрать навески пигментов так, чтобы попасть в ΔE < 1.0 за минимум попыток.

Что тренируем

🏭 Производство и контроль качества

Бирка на ведро с QR-кодом хранит всю цепочку партии: кто варил, когда, какой лот основы/пигмента, фото до/после и ΔE. Отчёт клиенту формируется в один тап. Алерты по сырью считаются по вашей же Библиотеке рецептов.

📦 Новая бирка на ведро

Возьмёт текущие данные формы «Колорист» (артикул, мастер, основа+лот, лоты пигментов, ΔE/ΔL/ΔA/ΔB последнего замера, фото Эталона/Замеса, если они загружены).

👁 Контроль брака (CV)

Направьте камеру на линию/полотно — приложение ищет в реальном времени: смену цвета, смену фактуры/блеска, полосы по всей ширине, непрокрас, светлые и тёмные точки, а также прикидывает скорость линии. Это эвристический детектор по цвету и локальному контрасту, а не обученная нейросеть — чувствительность нужно подобрать под свою линию и материал, а найденное всегда стоит перепроверять глазами, прежде чем останавливать производство. При подтверждённом браке — громкий сигнал и вибрация, на фото брака всегда проставлены дата и время.

Нажмите «Запустить камеру», направьте на линию, затем откалибруйтесь по чистому бездефектному участку материала.
